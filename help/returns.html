반품·교환 안내

수령 후 7일 이내 마이페이지에서 신청

신청 방법

  1. 마이페이지 → 주문내역 → 해당 주문의 교환·반품 신청 버튼 클릭
  2. 사유 선택 (단순변심 / 상품하자 / 오배송 등)
  3. 회수 일정 확인 후 택배 회수 진행

비용 부담

사유왕복 배송비비고
단순 변심이용자 부담 (₩6,000)회수 시 차감
상품 하자회사 전액 부담증빙 사진 요청 가능
오배송회사 전액 부담즉시 처리
일부 반품이용자 부담남은 주문 무료배송 조건 재계산

반품·교환이 제한되는 경우

  • 상품 수령 후 7일이 경과한 경우
  • 이용자의 사용 또는 일부 소비로 가치가 현저히 감소한 경우
  • 위생용품, 개봉된 화장품·건강기능식품 (위생상 재판매 곤란 시)
  • 주문 제작 상품 (사전 고지된 경우)
  • 택, 라벨, 부속품 등 누락 시

교환 절차

  • 색상·사이즈 교환은 재고 상황에 따라 진행됩니다.
  • 해당 옵션이 품절인 경우 환불 또는 다른 옵션으로 교환 처리.
  • 다른 상품으로의 교환은 반품 후 재주문 부탁드립니다.

처리 기간

상품 회수 확인 후 영업일 기준 3~5일 이내에 환불 또는 교환 발송이 진행됩니다.
